# 🐾 PawCare – Pet Management System

PawCare is a Java-based web application designed to make pet care management easier. It connects pet owners, veterinarians, sellers, and administrators through a single platform.

## 🚀 Technologies Used

- Frontend: JSP, HTML, CSS, JavaScript
- Backend: Java Servlets
- Database: MySQL
- Database Tool: MySQL Workbench
- Server: Apache Tomcat
- IDE: Eclipse

## ✨ Features

- User Registration and Login
- Pet Management
- Veterinary Doctor Registration
- Doctor Application and Admin Approval
- Appointment Booking
- Pet Products and Shopping Cart
- Seller Registration and Listings
- Admin Dashboard

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/PRATYAYCHATTERJEE/PetNest.git
```

### 2. Import into Eclipse

- Open Eclipse.
- Select File → Import.
- Choose Existing Projects into Workspace.
- Select the cloned PawCare folder.

### 3. Database Setup

- Open MySQL Workbench.
- Create a MySQL connection.
- Open `database/petcare.sql`.
- Execute the SQL script to create the database and tables.

### 4. Database Configuration

Update your database connection settings in the project's Java database connection class.

Use your own MySQL username and password.

### 5. Configure Apache Tomcat

- Add Apache Tomcat to Eclipse.
- Configure the project with Tomcat.
- Start the server.

### 6. Run the Application

Right-click the project and select:

Run As → Run on Server.
